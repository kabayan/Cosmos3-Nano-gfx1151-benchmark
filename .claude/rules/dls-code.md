# コード変更時の必須チェック

## DLS参照
コードを変更・生成する前に `.claude/.dls/active.md` を確認すること。
1. **where 照合**: 変更対象ファイルが `where` に含まれるエントリを特定し、その判断を踏まえて実装する
2. **棄却案の確認**: 関連エントリの `rejected_alternatives` に含まれる案を再実装しない
3. **判断の記録**: 新たな技術判断が発生したら、実装コミット前にDLSエントリを作成する

## レッスン参照
`tasks/lessons.md` が存在する場合は確認し、記録済みのパターンに従うこと。
特にテスト・環境構築時の行動知識を見落とさないこと。
